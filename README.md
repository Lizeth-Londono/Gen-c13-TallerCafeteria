# Taller Sistema de Cafetería

Este proyecto corresponde a la actividad **31.4 - TIFC2DEV-JAVA-CJ10 - Laboratorio Cafetería - ENTREGA**.

En este taller trabajé diferentes conceptos básicos de Java vistos durante el bootcamp, entre ellos:

- Variables y tipos de datos.
- Operadores.
- `switch`.
- `while`.
- `do-while`.
- `for`.
- Arrays.
- Debugging.

También desarrollé ejercicios prácticos relacionados con un sistema de cafetería, documentando el código paso a paso desde mi proceso de aprendizaje.
